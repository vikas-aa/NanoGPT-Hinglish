\# NanoGPT-Hinglish



A small custom GPT-style conversational AI built from scratch using PyTorch.



\## Goal



NanoGPT-Hinglish is an experimental conversational language model

designed primarily for Roman Hinglish and English conversations.



\## Features



\- Custom GPT-style Transformer architecture

\- Custom tokenizer using Hugging Face Tokenizers

\- Roman Hinglish conversational dataset

\- Training and validation pipeline

\- Text generation

\- Interactive terminal chat

\- CPU-compatible training



\## Project Structure



\- `model.py` — NanoGPT model architecture

\- `train.py` — model training

\- `generate.py` — text generation

\- `chat.py` — interactive chatbot

\- `train\_tokenizer.py` — tokenizer training

\- `encode\_dataset.py` — dataset tokenization

\- `combine\_dataset.py` — dataset preparation

\- `filter\_hinglish.py` — Hinglish dataset filtering

\- `scan\_data.py` — dataset scanning



\## Current Status



This is an experimental small-scale language model project.

The current model is trained on a small Roman Hinglish dataset

and is intended for learning and experimentation.
